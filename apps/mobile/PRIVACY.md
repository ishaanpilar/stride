# Privacy

Stride is local-first. Your tasks, notes and projects stay on your device.

The network is used only for features you turn on:

- **Sync** (Dropbox, WebDAV or a self-hosted server) sends your data to the backend you choose.
- **AI** (DeepSeek or Claude, with your own API key) sends the content needed for the request to that provider. The morning briefing sends only task titles, dates, priorities, projects and contexts. API keys are stored on the device and are never synced.

The code also contains an optional anonymous usage heartbeat that can be turned off in Settings. Open question: whether Stride builds ship it enabled; check Settings → Data before relying on this document.
