# @stride/core

Shared domain logic for Stride desktop/mobile/cloud layers.

Includes:

- Task/project/area stores and actions
- Sync and merge logic
- Storage adapters and migration helpers
- Shared types and utilities

## Tests

Run from repository root:

```bash
bun run --filter @stride/core test
```
