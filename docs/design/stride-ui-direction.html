Stride UI Direction
Stride for Mac

A calmer, more native Stride

The window keeps today's job in front: what's next, and how far through the day you are. Navigation and controls follow the Mac's own conventions. The only loud things are one orange ribbon and one primary button, both taken from the icon.

What changes

  1. Sidebar becomes a real Mac sidebar. Translucent material, 28 pt rows, sentence-case group titles instead of tiny uppercase, a tinted selection, counts on the right.
  2. One toolbar. Search, the view controls grouped as one control, and the single primary action, Capture, as the only filled button.
  3. A real title. 26 pt view title with the count beside it, then today's progress as one thin orange line. That line is the signature.
  4. Quieter rows. No coloured left stripes or boxed badges. Title at 14 pt, notes at 12 pt, a project dot, and dates in accent text only when they matter. Overdue is red and says so in words.
  5. Both appearances done properly. Dark is its own palette, not an inversion, and follows the system setting.

Build order

  1. Tokens. New light and dark palette, type scale and radii in the existing theme variables, so every screen picks them up at once.
  2. Window and sidebar. Overlay title bar with the traffic lights inset, system sidebar material, new sidebar rows.
  3. Toolbar, title and task rows. The three things on screen all day.
  4. Capture, Assistant, Settings, menu bar panel. Brought in line with the same tokens.
  5. Audit. Keyboard focus rings, Reduce Transparency, Increase Contrast, Reduce Motion, largest text size.
