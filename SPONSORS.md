# Support Stride

Stride is a free, open-source, AI-powered organiser for the Mac, built by Ishaan Pilar with AI coding agents.

It is a young project. The best ways to help right now:

- Use it and [open an issue](https://github.com/ishaanpilar/stride/issues) when something breaks or feels wrong.
- Share what you would pay for: the [roadmap](README.md#roadmap) is shaped by real use.
- Contribute: see [CONTRIBUTING](docs/CONTRIBUTING.md). AI-assisted contributions are welcome.
- Star the repository so others can find it.

Stride builds on [Mindwtr](https://github.com/dongdongbh/Mindwtr). If Stride is useful to you, consider supporting Mindwtr's author too.
